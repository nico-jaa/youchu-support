## 使用帮助

### 怎样添加物品？

在物品页点击新增，选择手工填写或添加照片。名称必填，位置与到期日可留空；检查后点击保存。

拍照或选图只会产生待确认草稿；当前普通录入需手工核对名称和日期，不能把照片外观当作保质期依据。

### 怎样查找物品和位置？

物品页支持按名称或位置搜索；也可以进入位置页，按房间、柜子、抽屉逐层查看。位置最多三级，同名位置请核对完整路径。

删除位置时选择迁移目标或转为未指定，不会连带删除该位置的物品。

### 临期状态和提醒有什么区别？

到期列表中的临期范围为未来 1 至 7 天，今天、已过期和未设置日期分别显示。到期日按公历年月日保存。

提醒的提前天数可选 1、3、7 天，默认提前 7 天、当地时间 09:00。修改提醒规则不会改变列表的临期范围。每件物品在同一到期日只提醒一次，同一时刻的多件物品会合并提醒。

### 没有收到临期提醒怎么办？

到设置的临期提醒中检查是否开启、系统是否允许通知，以及待安排数量和覆盖日期；有错误时点击重新核对提醒。

再检查 iOS 通知、专注模式、通知摘要、声音和横幅设置。系统设置可能影响实际呈现；有日期的物品不代表一定存在未来可安排时刻。已经过期或当天提醒时刻已过且没有有效时刻时不会补发。

拒绝通知后可手工查看到期列表，不必为使用物品管理而授权。

### 相机、照片或识别不可用怎么办？

检查是否允许有处使用相机；设备不支持或权限受限时，可以改选相册照片或手工填写。照片载入失败时可重试或换图，已有表单会保留。

自动识别与语音普通入口仍在验证，暂未开放。识别失败、资源不可用或断网时，手工管理仍可继续；不要将不完整的日期当成已确认结果。

### 保存失败或内容冲突怎么办？

保存失败时保留当前草稿，按提示检查名称、位置和设备存储空间，再重试；没有成功提示前，不应假定物品已经保存。

若提示物品已被修改，请先保留填写内容，再退出并重新打开该物品，核对后编辑。请勿通过删除应用或清空本地库解决保存问题。

### 数据如何备份，能在其他设备查看吗？

当前只有本地存储，不提供账号或多设备同步。可使用系统设备备份保护数据，备份是否完成请在系统中核对。

删除 App 或清空本地数据可能使记录丢失，请先确认备份。当前没有应用内导出／导入功能，系统恢复行为仍需在目标设备验证。

### 怎样删除数据和管理权限？

可以在物品详情删除单件物品；在设置的本地数据区域确认清空全部物品、照片和位置。清空不能在应用内撤销。

应用中的删除不处理历史系统备份，也不删除你从系统相册选择的原始照片。需要时请分别在系统备份、相册和权限设置中管理。

### 支持网页打不开怎么办？

打开网页时会优先检查对应的 GitHub Pages 页面，连接失败或约 4 秒无响应时使用 GitCode。只有主动点击才检查，不会随应用启动后台探测。

检查成功后网络仍可能变化；浏览器未能加载时，可以返回本页，在备用网页中直接选择 GitCode，或通过邮箱联系。隐私和常见问题也能在应用内离线阅读。
